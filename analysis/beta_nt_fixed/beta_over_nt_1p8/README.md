# beta/Nt = 1.8

This line has accepted 1,000-replica masses at `Nt=2,3,4,5,6`. The selected
spatial sizes are `128,176,256,336,416`, respectively. The current `p=1`
continuum fit is reported in [`../comparison/`](../comparison/).

Every selected ensemble has a `first_stage/` directory containing its
thermalization and blocking-error plots. Historical finite-volume checks are
kept separately under [`validation/`](validation/).
