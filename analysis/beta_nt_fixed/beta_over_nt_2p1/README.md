# beta/Nt = 2.1

Only `Nt=2,3` currently have accepted masses. `Nt=4` fails the common
all-observable blocking-plateau gate. The 48,300-sweep `Nt=5` snapshot passes
its primary blocking gate but has no stable three-by-three asymptotic mass-fit
patch, so `mass` and `xi_exp` remain null. `Nt=1,beta=2.1` is an exact PCM
reference.

There are therefore too few accepted spacings for a continuum fit. Every
point, including the rejected and preliminary ones, has its first-stage plots
inside `first_stage/`.
